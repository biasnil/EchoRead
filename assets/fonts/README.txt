Fonts shipped with EchoRead (all SIL Open Font License 1.1 - see the OFL-*.txt files):
  Inter 18pt (used for the app itself and offered in the reader), Lora, Source Code Pro, Source Sans 3.
To add OpenDyslexic: put OpenDyslexic-Regular.otf (and Bold/Italic if you like) and its licence in this folder; it then appears in Settings -> Font.
Georgia, Times New Roman and Courier New come with Windows and are not bundled.
